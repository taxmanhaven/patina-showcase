# Changelog

## 0.7.4 (6 November 2026)
- One command to run it: `npx github:taxmanhaven/patina-showcase check draft.md`.
- Every mark now has a line, a column, a severity and a plain reason.
- Output as text, JSON, or inline notes on a GitHub pull request.
- Exit codes for CI and commit hooks, with `--fail-on gate|any|never`.
- Settings in `.patinarc.json`: a profile per file type, rules switched off, lines kept on purpose.
- `patina explain`, `patina rules` and `patina profiles`.
- An MCP server, so AI apps can check their own drafts: four tools and a rewrite prompt. Offline, no key.

## 0.7.3 (6 November 2026)
- Tells scan with eleven reader profiles, among them headline and testimonial.
- Predictability map: the sentences a model would have written first.
- The Copybook: every sentence set against human ranges from two published novels, with the norms shipped as numbers.
- Introductory comma and afterthought aside checks.
- Short-line workflow for headlines: brief, filter, blind cold read.
- A before and after picture: the opening of a short story, first AI draft beside the rewrite.
